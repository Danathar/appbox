later #63) against `Danathar/appbox`, each asking for a file, directory or
setting to exist so the repository can reach ACMM level 6. The owner paused
the repository in his hive and had one local Claude Code session coordinate
the work: six subagents, each opening one pull request from an `acmm/` branch
(A, B, C, D, E1, E2), plus the coordinator's own README, branch-protection and
ruleset changes. Every file describes appbox as it is, not a template.

- **Agent for every row:** local Claude Code session (Claude Opus 5.5), a
  coordinator plus one subagent per branch. Not a hive run. Commits are signed
  off and carry `Co-Authored-By` and `Claude-Session` trailers; PR bodies end
  with the session link.
- **PR column:** filled in as each pull request is opened. Where it says `-`,
  look the PR up by branch:

  ```sh
  gh pr list -R Danathar/appbox --state all --head acmm/<slug> --json number,state,mergedAt
  ```

- **Outcome:** the state when this file was written. The final outcome is
  added as a dated note below once the pull requests merge.
