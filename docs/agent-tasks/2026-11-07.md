# Agent task ledger: 2026-11-07

The ACMM onboarding. Hive's ACMM evaluation opened issues #16 to #59 (and
later #63) against `Danathar/appbox`, each asking for a file, directory or
setting to exist so the repository can reach ACMM level 6. The owner paused
the repository in his hive and had one local Claude Code session coordinate
the work: six subagents, each opening one pull request from an `acmm/` branch
(A, B, C, D, E1, E2), plus the coordinator's own README, branch-protection and
ruleset changes. Every file describes appbox as it is, not a template.

- **Agent for every row:** local Claude Code session (Claude Opus 5.5), a
  coordinator plus one subagent per branch. Not a hive run. Commits are signed
  off and carry `Co-Authored-By` and `Claude-Session` trailers; PR bodies end
  with the session link.
- **Merges:** the coordinator squash-merged each pull request after its
  checks passed and its Codex review findings were fixed.

## Found along the way

- `fix/quote-digest`, #67: `build-appbox.yml` passed `${DIGEST}` unquoted to
  `cosign sign` and `cosign verify` (shellcheck SC2086), which would have
  turned the new actionlint jobs red from their first run.
- `fix/rebuild-exit-status`, #70: `host/appbox-update` exited 1 after every
  successful rebuild, because its EXIT trap used a `local` variable that was
  gone by the time the trap ran under `set -u`. The new unit tests found it.

  the required checks (now required in the ruleset), the agent audit used a

  policy-check gaps (a quoted package name, and bracket access to the PR head
